# Meli

Welcome to the official **GitHub repository for Meli**.

---

## 🌐 About Meli

https://www.meli.org.au is a community-focused organisation committed to improving lives across Western Victoria through a wide range of services, including community support, disability services, early childhood education, and family support solutions.

We aim to empower individuals, families, and communities through inclusive, person-centred approaches.

---

## 🤝 Contributing

We welcome contributions from Meli team members and authorised collaborators.

Before contributing:

1. Review any existing documentation in this repository
2. Follow established templates and standards
3. Ensure changes align with Meli practices and governance
4. Submit a pull request with a clear description of your changes

## 🔐 Security

If you discover a security vulnerability, please **do not open a public issue**.

Instead, follow the process outlined in `SECURITY.md` or contact the appropriate internal team.
