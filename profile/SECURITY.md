# Security Policy

## 🛡️ Overview

Meli takes the security of our systems, services, and data seriously. This repository is part of our broader commitment to maintaining secure and reliable technology practices across the organisation.

We appreciate the efforts of security researchers and contributors who responsibly disclose vulnerabilities so they can be addressed promptly.

---

## 🔍 Reporting a Vulnerability

If you discover a security vulnerability, **please do not report it via public GitHub issues or discussions**.

Instead, report it responsibly using one of the following methods:

- 📧 **Email**: service.desk@meli.org.au *(or your internal security contact if applicable)*  
- 🧑‍💻 **Internal Channels**: Meli ICT Operations team (for staff)


### Preferred Language

We encourage you to use your native language when communicating technical concepts - we will obtain translation support where needed.


### When reporting, please include:

- A clear description of the vulnerability  
- Steps to reproduce the issue  
- Any proof-of-concept (PoC) or screenshots (if applicable)  
- Potential impact or risk  
- Suggested remediation (if known)

---

## ⏱️ Response Process

Once a report is received, Meli will:

1. **Acknowledge receipt** of the report as soon as possible  
2. **Assess the severity and impact** of the vulnerability  
3. **Work to remediate** the issue in a timely manner  
4. **Communicate updates** where appropriate  

We aim to resolve critical issues quickly while ensuring stability and safety of our systems.

---

## 📊 Supported Scope

This policy applies to:

- All repositories within the Meli GitHub organisation  
- Associated software, automation, and workflows managed by Meli  

Out-of-scope items may include:

- Third-party services not controlled by Meli  
- Vulnerabilities without demonstrable impact  
- Issues requiring unrealistic or impractical attack scenarios  

---

## 🤝 Responsible Disclosure Guidelines

We ask that you:

- Avoid exploiting vulnerabilities beyond what is necessary to demonstrate the issue  
- Do not access, modify, or delete data belonging to others  
- Do not disrupt services or systems  
- Maintain confidentiality until the issue has been resolved  

---

## 🙏 Acknowledgement

We value the contributions of individuals who help improve our security posture. Where appropriate, we may acknowledge responsible disclosures internally or publicly.

---

**Thank you for helping keep Meli secure.**
